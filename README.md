# NekoMusic for HarmonyOS

第三方音乐播放器客户端（ArkTS + ArkUI，HarmonyOS NEXT）。**应用本身不内置曲库，也不默认连接任何服务器。**

## 首次启动

1. 阅读并同意《技术架构与使用边界声明》
2. 选择接口服务器：
   - **使用 NekoMusic 资源**：填入社区常用地址（由第三方提供与维护）
   - **自己配置**：填写你自己的接口服务器地址

未经同意、未选择服务器之前，应用不会发起任何请求。

## 声明要点

- 本应用是纯本地客户端，开发者不运营音乐服务，不存储、不上传、不中转、不筛选、不编辑任何音乐内容
- 播放与下载在你的设备与你指定的服务器之间直接进行
- 你应自行确保所接入服务器及内容的合法授权

完整声明见应用首次启动页。

## 功能

- 首页推荐 / 最新 / 排行，搜索，歌单、收藏与音乐库
- 媒体会话（AVSession）、实况窗歌词、封面模糊背景
- 折叠屏两栏、四方向旋转、分屏与悬浮窗
- 客户端身份 v1（实例签名）与请求防重放（一次性 nonce + 原生 PoW）

## 构建

```bash
export DEVECO_SDK_HOME=<your harmony sdk>
hvigorw --mode module -p product=default assembleHap --no-daemon
```
